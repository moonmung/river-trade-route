# 데블스랜드 — 웹 보드게임

2~4명(대형 맵은 8명까지)이 휴대폰이나 PC 브라우저에서 같은 판에 참가하는 턴제 전략 게임이다(2명이면 일대일 대결). 카탄 기본판 규칙을 따라 주사위로 칸을 생산시키고 타일 사이 꼭짓점에 마을을 지어 도시로 올리며 변을 따라 길을 놓는다. 자원은 다른 플레이어나 은행, 바닷가 해상 교역로에서 바꾸고 자기 차례에 승리 점수(기본 10점, 방장이 10~20점으로 정함)에 먼저 닿으면 이긴다. 첫 버전은 한 사람이 Windows PC에서 게임을 열고 같은 로컬 네트워크에 있는 사람들이 접속하는 방식으로 설계했다.

이 문서의 앞부분은 **실행 방법과 구현·검증 결과**, 가운데 「게임 규칙 (카탄 기본판)」은 지금 구현된 규칙, 뒷부분(「카탄 기본판에서 참고할 점」부터)은 **1차 설계**다. 1차 설계의 독자 규칙(예보 생산, 납품 계약, 시장, 6라운드)은 카탄 기본판 규칙으로 바꾸면서 뺐다.

## 방장 PC에서 실행하기

필요한 것: Windows 10/11 PC, [Node.js](https://nodejs.org) 20.19 이상(LTS 권장, 개발 PC는 24.16.0), 참가자와 같은 와이파이(또는 같은 공유기에 유선 연결). 외부 서버, 포트 포워딩, 인터넷 연결(설치 후)은 필요 없다.

이 폴더에서 명령 프롬프트나 PowerShell 을 열고 처음 한 번 설치·빌드한다.

```bash
npm install
```

```bash
npm run build
```

그다음부터는 게임할 때마다 서버만 켠다.

```bash
npm start
```

`start-host.cmd` 를 더블클릭해도 된다. 처음 실행이면 설치와 빌드를 먼저 하고 서버를 켠다. 코드를 바꾼 뒤에는 `npm run build` 를 다시 실행한다.

서버가 켜지면 창에 접속 주소가 나온다.

```
  데블스랜드 서버가 실행 중입니다.

  이 PC에서 열기:        http://localhost:3000
  휴대폰·다른 PC에서 열기: http://192.168.0.23:3000   (Wi-Fi)
```

- 처음 실행하면 Windows 방화벽이 Node.js 의 네트워크 접근을 묻는다. **개인 네트워크**에 체크하고 허용한다. 공용 네트워크로 설정된 와이파이라면 Windows 설정에서 네트워크 프로필을 개인으로 바꾼다.
- 포트를 바꾸려면 PowerShell 에서 `$env:PORT=3001; npm start` 처럼 실행한다.
- 서버 창을 닫거나 `Ctrl+C` 를 누르면 서버가 꺼진다. 진행 중인 게임은 `data` 폴더에 저장되어 있어 서버를 다시 켜면 이어 할 수 있다(아래 「끊겼을 때 다시 들어오기」). 방장 브라우저만 닫는 것도 괜찮다.

## 휴대폰으로 참가하기

1. **방 만들기.** 방장 PC 브라우저에서 `http://localhost:3000` 을 열고 닉네임을 넣은 뒤 **승리 점수**(기본 10점, −·+ 로 10~20점)를 고르고 **방 만들기**를 누른다. 승리 점수는 게임을 시작하기 전까지 대기실에서 방장이 다시 바꿀 수 있다. 승리 점수를 포함해 대기실 규칙을 바꿔도 다른 사람의 준비는 풀리지 않고, 바뀐 규칙은 모두의 화면에 바로 보인다.
2. **초대.** 대기실에 사설 IP가 들어간 초대 링크(예: `http://192.168.0.23:3000/join/6QK8`)와 QR 코드가 나온다. 휴대폰 카메라로 QR 코드를 찍거나 링크를 메신저로 보낸다. 가상 어댑터(WSL, Hyper-V 등) 때문에 주소가 여러 개면 대기실의 **접속 주소** 목록에서 와이파이·이더넷 주소를 고른다.
3. **참가.** 같은 와이파이에 연결된 휴대폰에서 링크를 열면 바로 참가 화면이 나온다. 닉네임을 넣고 **참가하기**를 누른다. 방 코드만 알면 첫 화면의 **방 코드로 참가**로도 들어갈 수 있다.
4. **시작.** 모두 **준비하기**를 누르면 방장이 **게임 시작**을 누른다. 방장 포함 2~4명(대형·호수 맵은 2~8명)이 모두 접속해 있고 준비해야 시작된다. 2명이면 같은 규칙으로 일대일 대결을 한다. 대기실에서 방장은 맵 모양(육각형·마름모·대형·호수)과 땅 배치(황금 배치·섞기)를 고를 수 있고 고른 맵이 작은 그림으로 보인다. 은행의 **자원 카드**(종류마다 10~40장, 기본 19장)와 **발전 카드** 총 장수(10~50장, 기본 25장)도 정한다. 대형·호수 맵을 고르면 따로 바꾸지 않은 카드 장수는 사람이 많은 판에 맞춰 자원 카드 30장, 발전 카드 40장으로 늘어난다. **개수 제한**을 "없음"으로 고르면 길·마을·도시를 몇 개든 짓고 발전 카드도 떨어지지 않는다(정한 장수의 종류 비율대로 무작위로 뽑히고 더미가 줄지 않는다). 건설 버튼의 남은 수는 ∞ 로 보인다. **주사위**는 기본이 "고르게"이고 "무작위"(그냥 굴리기)로 바꿀 수 있다. 고르게 굴리면 두 주사위의 36가지 눈 조합을 카드 한 벌처럼 뽑아서(남은 카드가 6장보다 적으면 새 벌) 숫자마다 확률대로 고르게 나오고, 바로 앞 굴림과 같은 합은 덜 나오며, 자기 차례에 7 을 남보다 많이 굴린 사람은 7 이 덜(적게 굴린 사람은 더) 나오고, 오래 자원을 받지 못한 사람이 받는 숫자는 조금 더 잘 나온다. 60번 굴리는 판을 400번 재 보면 숫자별 확률과의 차가 무작위의 약 40%, 같은 숫자 연타가 약 3분의 1, 사람별 7 횟수 차가 약 70%, 숫자가 적은 사람의 가장 긴 가뭄이 약 75% 로 줄었다. 5명 넘게 들어와 있으면 4명까지인 맵으로는 바꿀 수 없다. 연결이 끊긴 사람을 내보낼 수도 있다. 방장은 대기실 아래쪽이나 게임 메뉴(☰ → 설정)의 **방 닫기**로 언제든 방을 없앨 수 있다. 그러면 남은 사람에게 "방장이 방을 닫았습니다"가 뜨며 처음 화면으로 돌아간다.
5. **재접속.** 새로고침하거나 화면이 꺼졌다 켜지면 같은 탭은 자동으로 같은 자리로 돌아간다. 탭을 닫았거나 서버·방장 PC를 다시 켠 경우는 아래 「끊겼을 때 다시 들어오기」를 본다. 끊긴 사람의 차례가 오면 게임은 그 사람을 기다린다.
6. **다음 판.** 게임이 끝나면 방장이 결과 화면에서 **같은 멤버로 새 게임 준비**를 눌러 대기실로 돌아간다.

접속이 안 될 때는 다음을 확인한다: 휴대폰이 게스트 와이파이나 모바일 데이터가 아닌 같은 와이파이에 있는지, 초대 주소가 서버 창에 나온 주소와 같은지, 방화벽의 개인 네트워크 허용, 공유기의 "AP 격리(기기 간 통신 차단)" 기능.

### 끊겼을 때 다시 들어오기

브라우저는 방에 들어갈 때 받은 참가 토큰을 저장해 두고 서버는 방과 게임 상태를 방장 PC의 `data/rooms.json` 에 저장한다. 그래서 쓰던 브라우저로 다시 열기만 하면 대부분 같은 자리와 같은 손패로 이어진다.

| 상황 | 다시 들어오는 법 |
| --- | --- |
| 새로고침, 휴대폰 화면 꺼짐, 와이파이 잠깐 끊김 | 따로 할 일이 없다. 화면이 다시 켜지면 1초 안팎에 같은 자리로 붙는다. 서버는 20초쯤 응답이 없는 사람을 연결 끊김으로 표시한다. |
| 게임 탭을 닫음 (같은 기기, 같은 브라우저) | 처음 화면을 열고 **진행 중인 게임으로 돌아가기**를 누른다. 초대 링크나 `/room/방코드` 로 열었다면 참가 화면의 **이전 자리로 돌아가기**를 누른다. |
| 방장 PC의 서버가 꺼졌다가 다시 켜짐 | 서버가 켜질 때 저장해 둔 방을 되살린다. 열려 있던 화면은 저절로 다시 붙고 닫혔던 화면은 바로 위 칸처럼 돌아온다. 되살린 직후에는 모두 연결 끊김으로 시작하며 차례인 사람이 돌아올 때까지 게임이 기다린다. |
| 방장 PC를 다시 켬 | `start-host.cmd`(또는 `npm start`)로 서버를 다시 켜고 방장은 이 PC에서 처음 화면을 열어 **진행 중인 게임으로 돌아가기**를 누른다. 공유기가 PC 주소를 바꿨으면 휴대폰에 저장된 토큰을 예전 주소에서만 쓸 수 있으니 아래 자리 넘기기로 들어온다. |
| 다른 브라우저나 다른 기기로 옮김 | 방장 화면 왼쪽 위의 **끊긴 자리 넘기기**를 눌러 그 사람 자리의 코드를 만든다. 새 기기로 그 창의 QR 코드를 찍으면 바로 그 자리로 들어가고 초대 링크를 열어 숫자 6자리를 넣어도 된다. |

자리 넘기기 코드는 10분 동안 한 번만 쓸 수 있으며 쓰고 나면 예전 기기에 남은 토큰은 더 이상 통하지 않는다. 방장 자신이 끊겨 있을 때는 접속해 있는 다른 사람이 코드를 만들 수 있다. 끝난 게임과 하루 넘게 아무 일도 없던 방은 저장 파일에서 정리되므로 그런 방의 링크를 열면 "방을 찾을 수 없습니다"가 나온다.

서버를 켠 PC에서 처음 화면을 열면 아래쪽에 **남은 방** 목록이 나온다. 방마다 코드, 상태(대기실·게임 중·끝난 게임), 앉은 사람, 접속 인원이나 마지막으로 움직인 때를 보여 주고 **지우기**로 하나씩, **모두 지우기**로 한꺼번에 지운다. 지운 방에 접속해 있던 사람은 "서버를 켠 PC에서 이 방을 지웠습니다" 안내와 함께 처음 화면으로 돌아간다. 휴대폰 같은 다른 기기에서는 서버가 목록을 주지 않아 이 칸이 보이지 않고 지울 수도 없다.

## 실험실 모의 게임 (`/lab`)

플레이어를 여럿 모으지 않고 혼자 게임 화면을 시험하는 곳이다. `/lab` 을 열면 서버 없이 브라우저 안에서 규칙 엔진을 그대로 돌리는 3인 모의 게임이 실제 게임 화면 그대로 뜨고, 다른 자리는 봇이 순서 주사위·시작 배치·굴리기·건설·교환 제안과 응답·이모티콘까지 둔다. 차례 시간도 서버처럼 잰다. 왼쪽 가장자리의 **🧪 실험** 서랍에서 할 수 있는 일은 다음과 같다.

- **맵**: 서랍 맨 위에 육각형·마름모·대형·호수 맵이 작은 그림으로 놓여 있어 누르면 바로 그 맵으로 새 게임이 열린다. 아래의 황금 배치·섞기도 누르는 즉시 적용되고 섞기는 누를 때마다 새로 섞는다. 4명까지인 맵으로 바꾸면 인원은 4명으로 줄어든다. 새 게임을 열어도 서랍은 열린 채로 있어 맵을 연달아 바꿔 볼 수 있고, 고른 맵은 새로 고쳐도 그대로 남는다.
- **보는 자리**: 나·버들·물레(·나루) 중 누구의 화면으로 볼지 바꾼다. 그 자리는 봇 대신 직접 둔다. 봇을 끄면 모든 자리를 번갈아 직접 둘 수 있다.
- **게임**: 2~4명(대형·호수 맵은 8명까지) 새 게임, 순서 주사위 건너뛰기, 순서 정하기·시작 배치 자동 진행, 차례 시간 바꾸기와 멈춤.
- **주사위**: 다음 굴림의 합을 정한다(누가 굴리든 한 번). **내 땅 숫자**를 누르면 내 마을이 닿은 숫자로 정해져 카드가 손으로 날아드는 연출을 바로 볼 수 있다. **7**로 버리기·동상 흐름을 시험한다.
- **자원·카드**: 나에게 자원을 주거나 비우고, 발전 카드 다섯 가지를 바로 받는다.
- **연출**: **⛵ 해양 교역 배**는 내 마을이 교역로에 없으면 하나 지어 준 뒤, 내 차례 교환 단계면 실제 교역로 교환을 해서 배가 들어와 짐을 주고받는 모습을 보여 준다(그 밖의 단계에서는 연출만). 승리 화면도 바로 띄운다. **달성 공지** 줄의 최장 교역로·최강 기사단 버튼은 누를 때마다 다음 자리의 색으로 공지를 띄워 색마다 어떻게 보이는지 확인할 수 있다.

개발 모드(`npm run dev`)에서는 콘솔의 `__lab.sb`(모의 게임)와 `__lab.renderer()`(3D 보드)로 상태를 직접 다룰 수 있다.

| 3D 보드 | 한 손가락(마우스 왼쪽) 끌기로 이동, 두 손가락 벌리기(휠)로 확대·축소. 칸마다 한가운데에 숫자 패(빨간 6·8, 나올 확률 점)가 있다. 타일·꼭짓점·변을 눌러도 설명 쪽지는 뜨지 않고 그 자리에서 할 수 있는 일(시작 마을과 길 놓기, 길 놓기, 마을 짓기, 도시로 업그레이드, 기사단 동상 옮기기)이 있을 때만 고른 자리 바로 위에 동그란 단추 두 개가 붙는다. 주사위 굴리기 단추와 같은 남색 ✓ 를 누르면 그 일을 하고 빨간 ✕ 는 고른 것을 무른다. 글로 된 설명은 없고, 보드를 끌거나 확대해도 단추는 그 자리를 따라다닌다. 재료가 모자라는 등 못 하는 일이면 ✓ 가 회색으로 흐려지고 누르면 까닭이 알림으로 뜬다. 판정 반경은 확대 수준과 상관없이 손가락 크기 그대로이고 기록에서는 칸 코드 대신 "곡물 10", "곡물 10·석재 4 사이"처럼 자원과 숫자로 자리를 부른다. 내 차례에는 건설 버튼을 누르지 않아도 길을 이을 수 있는 변(점선)과 마을을 지을 수 있는 꼭짓점(고리)이 은은하게 보인다. 길에 마우스를 올리면(휴대폰은 길을 누르면) 그 주인의 가장 긴 교역로가 금빛으로 그려지고 이어진 길 칸 수와 최장 교역로까지 남은 칸도 작은 창에 함께 나온다. 누른 타일의 소품은 톡 튀고 마을·도시·길은 한 번 부풀었다 돌아온다. 마을·도시 위 주인 표시(그 사람 색으로 칠한 사람 아이콘)는 바로 위쪽 길을 가리지 않게 평소에는 숨겨 두고 지붕 색으로만 구별하다가 마을·도시를 누르면 그 위에 톡 떠오르고 다른 자리를 누르거나 같은 건물을 다시 누르면 사라진다. |
| 차례 상태 쪽지 | 예전 위쪽 띠는 없앴다. 넓은 화면은 오른쪽 패널 맨 위, 휴대폰은 보드 왼쪽 위에 작은 쪽지가 뜬다. 메뉴(☰), 턴 번호, 마지막 주사위(3D 주사위가 구르는 동안에는 "굴리는 중…"), 승리 점수, **남은 차례 시간**(모래시계와 45, 1:30 같은 숫자를 담은 먹색 패, 아래쪽 가는 띠가 남은 만큼 줄고 10초 아래면 패가 붉어지며 뛴다)과 지금 할 일 한 줄이 있다. 내 시간이 흐를 때는 쪽지 아래 가장자리에 남은 시간 막대도 줄어든다. |
| 오른쪽 위 교환 증서 | 열린 교환 제안마다 작은 종이 쪽지가 한 장씩 쌓인다. 글은 줄이고 아이콘으로 보여 준다. 위아래 두 줄에 사람 아이콘과 그 사람이 내놓는 자원 아이콘(오른쪽 위 밀랍에 장수)을 놓고, 가운데 ▼(위 줄 자원이 아래로) ▲(아래 줄 자원이 위로)로 주고받는 방향을 보인다. 보는 사람 기준으로 내 쪽이 아래 줄이고, 교환에 끼지 않은 사람에게는 제안자가 아래 줄이다. 그 아래에는 받은 사람마다 아이콘에 ✓(수락)·✕(거절)·…(생각 중) 딱지가 붙는다. 받은 사람은 **수락**·**거절**을 누르며 수락한 뒤에도 **수락 취소**로 거절로 바꿀 수 있다. 수락만으로는 카드가 옮겨지지 않고 제안한 사람이 ✓ 가 붙은 사람 아이콘을 눌러야 그 사람과 교환이 이루어진다. 새 증서는 제자리에서 옅게 떠오른다. 모두 거절하면 "거절됨", 취소하면 "취소됨", 성사되면 "체결" 글씨가 증서 가운데 뜨고 증서는 크기나 자리가 바뀌지 않은 채 3초쯤 머물다가 옅어지며 사라진다(이때 따로 알림은 없다). 일대일 대결에서는 받는 사람이 한 명뿐이라 "모두에게" 대신 그 사람 이름으로 제안한다. |
| 아래쪽 | **손에 든 카드**: 화면 아래 띠에 한 줄로 가지런히 든다(넓은 화면 70×100, 휴대폰 56×80). 자원 카드와 발전 카드 모두 종류마다 한 장을 앞에 두고 뒤에 겹친 두께와 숫자로 장수를 보여 준다. 교역로에 닿은 자원에는 비율 띠, 지금 쓸 수 있는 발전 카드에는 빛나는 테두리, 이번 턴에 산 카드에는 "새 카드" 띠가 붙는다. 자원 카드를 누르면 교환 창이 열리면서 그 카드가 낼 것에 들어가고 발전 카드를 누르면 카드 위에 쓰기 창이 붙는다(풍년은 자원 2개, 독점은 1개를 골라서 쓴다). 카드 그림은 자원 다섯 가지(통나무, 볏단, 양, 벽돌 더미, 돌덩이)와 발전 카드 다섯 가지(기사 투구, 길 건설 판자 길 두 조각과 ×2 딱지, 풍년 곡식 바구니, 독점 저울, 승점 왕관) 모두 수채화 그림이다. **버튼 줄**: 카드 오른쪽에 [교환] [도로] [마을] [도시] [발전 카드] [턴 종료]가 같은 크기로 한 줄에 놓인다. 넓은 화면에서는 버튼을 손 카드 높이만큼 세로로 늘려 띠 위쪽에 빈자리가 남지 않고, 휴대폰은 카드 아래에 여섯 칸 한 줄로 둔다. 건설 버튼에는 판자 길 한 조각, 작은 집, 성벽 두른 마을, 발전 카드 뒷면 그림을 크게 두고 이름은 작게 적으며, 오른쪽 위 모서리 딱지에 앞으로 더 지을 수 있는 개수(도로 15·마을 5·도시 4개에서 지은 만큼 빠짐, 발전 카드는 더미에 남은 장수)를 적는다. 다 쓰면 딱지가 붉어진다. 재료는 마우스를 올리거나 누르면 버튼 위 말풍선에 아이콘과 개수로만 나오고 모자란 재료는 흐리게 보인다. 못 하는 버튼을 누르면 까닭(예: "벽돌 1 더 필요합니다.")은 교환 버튼처럼 알림으로 뜬다. 도로·마을·도시는 누르면 지을 수 있는 자리가 빛나고 그 자리를 고르면 자리 위에 ✓ / ✕ 가 떠서 ✓ 를 눌러야 지어진다. 길 건설 카드도 빛나는 변을 고를 때마다 ✓ / ✕ 가 떠서 길을 하나씩 확인하며 놓는다. 발전 카드 버튼은 누르면 바로 산다. 맨 왼쪽 **교환**에는 은행과 바로 바꿀 수 있는 자원이 있으면 황토 점이 붙고, 맨 오른쪽 칸은 굴리기 전에는 **주사위 굴리기**, 굴린 뒤에는 **턴 종료**다. |
| 교환 창 | 손에 든 카드 바로 위에 열린다. 위 줄 **▼ 받을 것**과 손에 맞닿은 아래 줄 **▲ 낼 것**에 자원 카드 다섯 장이 놓여 있어 누르면 한 장(은행은 한 묶음)씩 더해지고 카드 위의 − 로 뺀다. **은행·교역로** 탭의 카드마다 지금 내 비율(4:1, 교역로 3:1·2:1)이 찍혀 있고 그만큼 모인 자원만 고를 수 있다. 여러 묶음을 한 번에 내도 되며 받을 카드 수가 묶음 수와 맞으면 "은행과 교환 · 석재 4 → 벽돌 1"처럼 버튼에 내용이 나온다. 은행 탭 아래에는 긴 설명 대신 내 비율만 아이콘으로 적는다. **플레이어와 거래** 탭에서는 가진 카드에서 낼 것을, 원하는 카드를 받을 것에 고른 뒤 **모두** 또는 사람 아이콘 하나를 골라 제안한다. 제안은 여러 번 낼 수 있고 동시에 3개까지 열어 둘 수 있어서 버튼에 "모두에게 제안 (1/3)"처럼 열린 수가 함께 적혀 있다. |
| 오른쪽 아래 | **은행**: 플레이어 상태 창 바로 위에 자원 다섯 가지와 발전 카드를 손 카드와 같은 물감 색의 작은 카드 더미로 그리고, 오른쪽 위 먹색 딱지에 은행에 남은 장수(발전 카드는 더미에 남은 장수)를 적는다. 세 장 이하는 황토색, 다 떨어지면 카드가 흐려지고 딱지가 붉어진다. 휴대폰은 상태 창 아래에 아이콘과 숫자만 한 줄로 보인다. **플레이어 상태 창**: 사람마다 왼쪽에 그 사람 색으로 칠한 사람 아이콘, 이름 줄에 이름·최장 교역로·최강 기사단 꼬리표·열린 교환 제안 수(⇅)·시간이 흐르는 사람의 남은 시간, 아랫줄에 발전 카드 뒷면과 장수·쓴 기사·가장 긴 길·자원 카드 뭉치와 장수가 있고, 오른쪽 아래에 공개 승점을 큰 숫자로 적는다. 휴대폰 두 칸 꼴과 아주 낮은 화면에서는 승점을 이름 줄 오른쪽에 둔다. 지금 차례인 사람에게는 그 색 테두리가 둘린다. 휴대폰에서는 차례 상태 쪽지 아래에 두 칸씩 나란히 작게 놓여 보드를 가리지 않고, 채팅(💬)·이모티콘(😊) 단추만 오른쪽 아래 구석에 있다. 창을 줄이면 오른쪽 패널 폭이 함께 줄고, 낮아지면 최근 기록 → 대화 순으로 접히며, 아래 띠는 카드와 버튼을 줄여 한 줄을 지킨다. |
| 자원이 들어올 때 | 주사위로 생산하면 칸이 금빛으로 빛나고 생산물이 마을·도시로 날아간 뒤, 그 자리에서 **자원 카드가 손으로 날아든다**. 내 자원이 나온 칸은 바닥이 따뜻한 빛으로 잠깐 환해지고(보드 전체가 아니라 그 칸만), 내 카드는 큼직하게 내 손의 그 자원 자리로 슉슉 들어오며, 다른 사람의 카드는 작게 그 사람 상태 창 오른쪽 아래 카드 뭉치로 슈루룩 빨려 들어간다. 여러 장이면 그만큼 날아가고 장수는 카드가 닿을 때 하나씩 오른다. 두 번째 시작 마을을 지을 때 받는 자원도 같다. |
| 이번 턴 기록 | 보드 왼쪽 위(휴대폰은 차례 상태 쪽지 아래)에 이번 턴에 한 일(주사위, 생산, 동상, 빼앗기, 건설, 교환, 발전 카드 등)이 그 사람 색 띠와 아이콘을 단 한 줄씩 쌓인다. 한 줄은 12초쯤 떠 있다가 마지막 4초 동안 천천히 옅어져 사라지고, 다음 사람 차례가 되면 지난 턴 줄은 빨리 걷힌다(휴대폰은 최근 세 줄만). 턴 넘기기, 교환 응답 하나하나, 순서 주사위는 띄우지 않는다. 맨 위 **기록** 단추를 누르면 **전체 기록**이 화면 가득 열려 처음부터 지금까지를 턴별로 묶어(최근 턴이 위, 그 턴을 둔 사람 색 띠와 이름) 보여 준다. Esc 나 ✕ 로 닫는다. |
| 기록·대화 | 넓은 화면 오른쪽 패널의 **최근 기록**에는 점수와 이어진 일(마을·도시 +1점, 최장 교역로·최강 기사단, 게임 끝)과 발전 카드를 사고 쓴 일만 작은 글씨로 남는다. 시작 배치, 주사위, 생산, 교환, 길처럼 누가 무엇을 받았는지는 **전체 보기**(왼쪽 위 기록 단추와 같은 전체 기록 창)나 메뉴의 기록에 있다. 그 아래 **대화**에서는 같은 방 사람끼리 120자까지의 짧은 글을 주고받으며 👍 😂 😮 😡 🎉 🤝 단추를 누르면 내 이름 옆에 그 이모티콘이 잠깐 떠오른다. 서버가 방마다 최근 50개를 보관하니 새로고침해도 대화가 남아 있고 너무 빨리 이어 보내면 "조금 천천히 보내 주세요."라는 답과 함께 막힌다. 대기실에서도 같은 대화를 쓸 수 있다. |
| 핑 | 보드 한 자리(칸·꼭짓점·변)를 모두에게 가리킨다. 넓은 화면은 이모티콘 줄 오른쪽 끝의 **핑** 단추, 휴대폰은 오른쪽 아래 둥근 단추를 눌러 켜고 보드를 누르면 찍히며, 마우스로는 Alt 키를 누른 채 보드를 눌러도 바로 찍힌다. 찍힌 자리에는 깃대 하나에 그 사람 색 삼각 깃발을 단 간단한 깃발이 톡 떨어져 꽂히고 땅에 고리 하나가 퍼진다. 꽂힌 깃발은 움직이지 않고 2.6초 동안 서 있다가 옅어진다(이름은 적지 않는다). 난사하지 못하게 한 사람이 연달아 3번까지 찍을 수 있고 그 뒤로는 1초에 한 번씩 다시 생기며(쉬면 3번까지 모인다), 넘기면 알림 없이 그냥 찍히지 않는다(서버와 화면이 같이 센다). 핑 찍기가 켜져 있는 동안은 보드 커서가 십자로 바뀌고 Esc 나 그만두기로 끈다. |
| 달성 공지 | 최장 교역로나 최강 기사단을 누가 차지하면 화면 위쪽에 "빨강 플레이어 최장 교역로 달성"처럼 그 플레이어 색 이름과 색으로 공지 띠가 4초쯤 내려온다. 아래 줄에는 닉네임, 이어진 길 칸 수나 쓴 기사 수, +2점, 누구에게서 가져왔는지가 나온다. |
| 자랑하기 | 최장 교역로나 최강 기사단을 가지고 있으면 이모티콘 줄 옆(휴대폰은 오른쪽 아래)에 금빛 **자랑** 단추가 생긴다. 내 상태 창의 달성 표식을 눌러도 된다. 누르면 같은 방 모두의 화면에 달성 때와 같은 연출(보드 위 금빛 훑기·동상 뛰기와 큰 글자)이 "빨강 플레이어 최장 교역로를 뽐냅니다"라는 글로 다시 뜬다. 지금 가진 달성만 뽐낼 수 있고 한 사람이 5초에 한 번이다(서버와 화면이 같이 센다). |

WebGL 을 쓸 수 없는 기기에는 예전 2D 주사위 그림이 대신 나온다. |

## 실제 기기에서 추가로 확인할 항목

- [ ] Android Chrome, iPhone Safari 에서 QR 코드·초대 링크로 처음 들어갈 때 걸리는 시간과 3D 보드 첫 로딩 시간
- [ ] `/lab` 과 실제 게임에서 이동·확대 중 프레임(목표 30fps), 해상도 배율이 자동으로 내려가는지
- [ ] 기본 줌에서 물자 다섯 종류와 마을·도시·길 소유자(지붕·판자 색)를 알아볼 수 있는지, 마을·도시를 눌러 뜨는 사람 아이콘 색으로 주인을 알 수 있는지
- [ ] 손가락으로 타일을 원하는 대로 누를 수 있는지(특히 앞줄 D, 나무가 겹치는 뒷줄 A), 두 손가락 확대와 한 손가락 이동이 불편하지 않은지
- [ ] iPhone 에서 KTX2(ASTC)·GLB 가 정상으로 보이는지. 실패한 모델은 코드로 만든 단색 대체 모델로 나온다. `/lab` 화면 아래 에셋 줄에 "GLB 47개, KTX2 8개"가 나오고 대체 모델 수가 없으면 정상이다
- [ ] 휴대폰 화면을 끄거나 다른 앱을 갔다 왔을 때 자동 재접속, 와이파이를 잠깐 끊었을 때 같은 자리로 돌아오는지
- [ ] Windows 방화벽 허용 창, 공유기 AP 격리 여부, 게스트 와이파이에서 접속 실패 시 안내가 충분한지
- [ ] 3인·4인 실전 테스트(설계 6단계): 한 판 시간, 숫자 패와 교역로 위치의 균형, 7과 기사단 동상이 교환에 미치는 영향, 보드 움직임을 켠 채 휴대폰 배터리와 발열
- [ ] Android 에서 내 차례·교환 제안이 올 때 진동이 거슬리지 않는지

1. Blender 에서 모델을 만들 때 단위는 타일 한 칸 = 2.0, 원점은 바닥 가운데, +Y 위, +Z 가 카메라(앞) 쪽이다. 집은 가로 약 0.66, 높이 약 0.75 를 기준으로 한다.
2. 재질 이름은 `M_wood`, `M_stone`, `M_roof` 처럼 `M_<키>` 를 쓴다. 화면에서는 이 이름의 재질을 `art/materials.ts` 의 색으로 만화 음영 재질을 다시 만들므로, Blender 에서는 꼭짓점 색으로 밝기와 무늬를 칠한다. `M_roof`(지붕)와 `M_banner`(깃발)는 플레이어 색이 곱해지므로 밝은 무채색으로 칠한다. 텍스처를 꼭 써야 하는 재질은 `M_` 로 시작하지 않는 이름을 쓰면 GLB 의 색과 텍스처를 그대로 가져온다.
3. glTF 로 내보내고, 텍스처가 있으면 KTX2 로 압축한다(예: KTX-Software `toktx` 나 glTF-Transform 의 `etc1s`/`uastc`). 소품마다 따로 내보내도 되고 키트 한 파일로 내보내도 된다.
4. `public/art/manifest.json` 의 해당 항목 `url`(및 키트 안의 `node`)을 새 파일로 바꾸고 `"temporary": false` 로 고친다. 서버를 다시 시작할 필요는 없고 `npm run build` 만 다시 한다.
5. `npm run assets` 는 임시 에셋과 manifest.json 을 **다시 생성**하므로, 최종 에셋으로 바꾼 뒤에는 실행하지 않는다.

### 시작

- **자리 순서 정하기**: 게임을 시작하면 모두 동시에 주사위를 굴린다(화면 가운데 창의 **주사위 굴리기**). 높은 사람이 먼저이고 가장 낮은 사람이 마지막이다. 같은 수가 나온 사람끼리만 다시 굴려 그 사이 순서를 정한다.
- 정해진 자리 순서대로 한 바퀴 돈 뒤 거꾸로 한 바퀴 돌며 각자 마을 하나와 그 마을에 붙은 길 하나를 놓는다. 빛나는 꼭짓점을 고르면 그 위에 뜨는 파란 **✓** 를 눌러 마을을 짓고(모두에게 바로 보인다), 이어서 그 마을에 붙은 빛나는 변을 고르고 **✓** 를 눌러 길을 놓아야 다음 사람으로 넘어간다. 잘못 골랐으면 빨간 **✕** 로 무른다. 두 번째 마을은 지을 때 닿은 생산 칸마다 자원 1장을 바로 받는다.
- **거리 규칙**: 마을·도시 바로 옆 꼭짓점(변 하나 거리)에는 누구도 마을을 지을 수 없고 시작 배치에도 같이 적용된다.
- 상대 자원은 총량만 공개되고 종류별 보유량은 본인 화면에서만 보인다. 발전 카드도 장수만 공개된다.

### 차례 진행

1. **주사위.** 차례인 사람이 주사위 두 개를 굴린다. 합과 같은 숫자 패가 놓인 칸에 닿은 마을은 그 칸 자원 1장, 도시는 2장을 받는다. 차례가 아닌 사람도 받지만 기사단 동상이 선 칸은 생산하지 않는다.
2. **7이 나오면** 아무 칸도 생산하지 않는다. 자원이 **보유 한도**(기본 7장, 방장이 대기실에서 5~20장으로 정함)보다 많은 사람은 모두 절반(내림)을 골라 버린다. 방장이 대기실의 **7 버리기**를 없음으로 하면 아무도 버리지 않고 보유 한도 줄도 감춘다(기본은 있음, 예전 저장 게임도 있음으로 이어 간다). 굴린 사람은 동상을 다른 칸으로 옮긴 뒤 그 칸에 마을·도시가 닿은 상대 한 명에게서 자원 1장을 무작위로 가져온다(닿은 상대가 한 명이면 바로 가져온다).
3. **교환·건설·발전 카드.** 횟수 제한 없이 원하는 순서로 하고 턴을 끝낸다.
4. **차례 시간.** 한 차례는 기본 1분이다(방장이 대기실에서 제한 없음·30초~3분으로 정함). 순서 주사위·시작 배치·7 버리기에도 같은 시간이 흐른다. 시간이 다 되면 서버가 대신 진행한다: 굴리지 않았으면 굴리고, 동상은 남의 마을이 닿은 칸으로, 빼앗기·버리기는 무작위로, 시작 배치는 점이 가장 많은 자리에 마을과 길을 놓고, 교환·건설 단계는 턴을 넘긴다. 아무도 접속해 있지 않으면 시계가 멈추고 누군가 돌아오면 그 차례를 처음부터 다시 잰다.

| 행동 | 처리 방식 |
| --- | --- |
| 길 놓기 | 목재 1, 벽돌 1. 내 마을·도시나 내 길에 이어지는 빈 변에만 놓는다. 남의 마을·도시가 선 꼭짓점을 지나서는 잇지 못한다. 최대 15개. |
| 마을 짓기 | 목재·벽돌·양모·곡물 1장씩. 내 길이 닿은 빈 꼭짓점에 거리 규칙을 지켜 짓는다. 최대 5개(개수 제한 없음이면 끝이 없다), 1점. |
| 도시로 업그레이드 | 곡물 2, 석재 3. 새 자리에는 지을 수 없고 이미 있는 **내 마을**만 도시로 바꾼다. 최대 4개, 2점. 그 꼭짓점의 생산은 칸마다 2장이 되며 돌려받은 마을 조각은 다시 쓸 수 있다. |
| 발전 카드 사기 | 곡물·양모·석재 1장씩. 남은 덱에서 한 장을 뽑는다. 개수 제한 없음이면 덱이 줄지 않고 처음 구성에서 무작위로 뽑는다. |
| 은행·교역로 교환 | 주사위를 굴린 뒤 내 차례에 한다. 교역로가 없어도 같은 자원 4장 → 원하는 자원 1장. 3:1·2:1 교역로에 닿아 있으면 그 비율. 여러 묶음(예: 목재 8장 → 2장)을 한 번에 바꿀 수 있다. 은행에 남은 만큼만 받을 수 있고 교환 창의 받을 카드 아래에 은행에 남은 장수가 나온다. |
| 은행 자원 카드 | 은행에는 자원마다 방장이 정한 장수(기본 19장)가 있다. 생산·시작 마을 자원·은행 교환·풍년은 은행에서 꺼내고 건설·발전 카드 값·버리기·은행 교환으로 낸 자원은 은행으로 돌아간다. 한 자원을 여러 사람이 받아야 하는데 은행에 모자라면 그 자원은 아무도 받지 못하고 받을 사람이 한 명이면 남은 만큼만 받는다. 이때 기록에 "은행에 곡물이(가) 모자라…"가 남는다. |
| 플레이어와 교환 | 차례인 사람이 줄 자원과 받을 자원을 정해 다른 사람 모두(또는 한 사람)에게 제안한다. 받은 사람이 각자 수락·거절하면 제안한 사람이 수락한 사람 중 한 명을 고르면 서버가 양쪽 잔고를 다시 확인한 뒤 한 번에 옮긴다. 모두 거절하거나 취소하거나 턴을 넘기면 그 제안은 닫힌다. 같은 종류를 양쪽에 넣을 수 없다. 제안은 여러 번 낼 수 있으며 같은 내용이 아니면 동시에 3개까지 열어 둔다. 한 교환이 확정되면 남은 제안을 다시 보고 낼 자원이 모자란 제안은 닫고 받을 자원이 모자라게 된 사람의 수락은 되돌린다. 제안 내용은 모두에게 공개되지만 서로의 종류별 보유량은 보이지 않는다. |

### 발전 카드 (기본 25장)

기사 14장, 승점 5장, 길 건설 2장, 풍년 2장, 독점 2장이다. 방장이 총 장수를 10~50장으로 바꾸면 이 비율로 나누고 다섯 종류가 모두 한 장 이상 들어간다(10장이면 기사 5, 승점 2, 나머지 1장씩). 한 턴에 한 장만 쓸 수 있고 산 턴에는 쓰지 못한다. 기사는 내 차례라면 주사위를 굴리기 전에도 굴린 뒤에도 써서 동상을 옮기고 한 장을 빼앗는다. 길 건설은 공짜 길 2개, 풍년은 은행에서 자원 2장, 독점은 다른 사람들이 가진 한 종류 자원을 모두 가져온다. 승점 카드는 숨겨 두었다가 10점을 셀 때 더한다.

### 점수와 승리

마을 1점, 도시 2점, 승점 카드 1점에 두 가지 달성 점수를 더한다.

- **최장 교역로**(2점): 끊기지 않고 이어진 길이 5개 이상이면서 가장 긴 사람. 남의 마을·도시가 길 중간에 서면 거기서 끊긴다. 지금 가진 사람과 같은 길이면 넘어가지 않는다. 가진 사람이 밀려난 뒤 공동 1위가 여럿이면 아무도 갖지 않는다.
- **최강 기사단**(2점): 기사 카드를 3장 이상, 지금 가진 사람보다 많이 쓴 사람.

자기 차례에 10점에 먼저 닿은 사람이 바로 이긴다.

## 카탄 기본판에서 참고할 점

카탄은 3~4인용 자원 관리·교역 게임이다. 공식 소개의 플레이 시간은 60~90분이다. 19개 육각 지형으로 만든 섬에서 교차점에는 정착지나 도시를, 타일의 변에는 도로를 놓는다. 주요 자원은 목재, 벽돌, 양모, 곡물, 광석이다. [카탄 공식 소개](https://www.catan.com/catan)

| 단계 | 기본판 진행 |
| --- | --- |
| 시작 배치 | 정착지와 도로 한 쌍씩을 순서대로 놓고, 역순으로 한 쌍을 더 놓는다. 두 번째 정착지 주변 지형에서 시작 자원을 얻는다. |

| 승리 | 정착지·도시, 최장 교역로·최대 기사단 보너스, 일부 개발 카드로 점수를 얻는다. 자신의 차례에 10점 이상이면 즉시 승리한다. |

배치가 생산과 확장 가능성을 바꾸고, 다른 사람과 자원을 바꾸면 각자의 다음 행동이 달라진다. 이 두 가지를 웹 게임의 핵심으로 삼았다. 1차 설계에서는 독자 규칙 초안을 따로 두었지만 지금은 위 「게임 규칙 (카탄 기본판)」을 구현했다.

## 같은 와이파이에서 참가하는 방법

1. **방 열기.** 방장 PC에서 Node.js 서버를 실행한다. 같은 서버가 웹 파일을 제공하고 Socket.IO로 방과 게임 상태를 동기화한다. 서버는 로컬 네트워크에서도 접근할 수 있게 예시 포트 `3000`으로 수신한다. [Node.js 수신 주소 문서](https://nodejs.org/api/net.html#serverlistenport-host-backlog-callback)
2. **초대.** 방장이 브라우저에서 닉네임을 입력하고 방을 만든다. 다른 사람에게 방장 PC의 사설 IP와 방 코드가 들어간 링크를 알려준다. 예시 주소는 `http://192.168.0.23:3000/join/6QK8`이다. 참가자는 같은 와이파이에서 링크를 열고 자기 닉네임을 입력한다.
3. **시작.** 대기실에서 자리와 접속 상태를 확인한다. 방장 포함 3~4명이 모두 준비하면 방장이 시작한다. 게임 시작 후에는 기존 자리로 재접속할 수 있다.
4. **재접속.** 브라우저에 저장된 참가 토큰으로 새로고침이나 일시적인 와이파이 끊김 뒤에 같은 자리로 돌아온다. 끊긴 사람의 턴이나 시작 배치 차례가 오면 대기하고, 다시 연결되면 서버가 현재 상태를 보내 이어서 진행한다. 방장 브라우저를 닫아도 서버 프로세스가 켜져 있으면 방은 유지된다. 첫 버전은 진행 상태를 메모리에 보관하므로 방장 PC가 꺼지거나 서버가 재시작되면 해당 판은 종료된다.

이 구성에는 외부 서버 구매나 공유기 포트 포워딩이 필요 없다. 같은 와이파이에서도 게스트 네트워크가 기기 간 통신을 막을 수 있다. 접속이 안 되면 방장 PC의 사설 IP, 같은 네트워크인지, Windows 방화벽에서 사설 네트워크의 게임 서버 앱 연결이 허용됐는지 확인한다. [Windows 방화벽 앱 허용 안내](https://support.microsoft.com/en-us/windows/security/firewall/risks-of-allowing-apps-through-windows-firewall)

## 첫 버전 화면과 판정

| 화면 | 필요한 정보와 동작 |
| --- | --- |
| 시작 | 닉네임, 방 만들기, 방 코드로 참가 |
| 대기실 | 초대 링크 복사, 참가자, 준비 상태, 시작 |
| 플레이 | 보드, 현재 차례, 남은 행동, 이번 예보와 다음 예보, 공개 계약, 내 자원, 교환 요청, 턴 종료 |
| 결과 | 순위, 납품 점수, 동점 판정에 사용한 남은 자원 |

서버가 방, 플레이어, 라운드, 턴, 보드, 자원, 계약, 교환 제안을 관리한다. 브라우저는 건설이나 납품처럼 하려는 행동만 보내고, 서버가 차례·비용·자리·계약 물량을 확인해서 반영한다. 교환은 그 자리의 참가자만 수락할 수 있으며, 서버가 양쪽 잔고를 다시 확인한 뒤 한 번에 옮긴다. 각 브라우저에는 공개 정보와 그 참가자 자신의 비공개 자원만 보낸다.

## 추천 기술 스택

| 영역 | 기술 | 역할 |
| --- | --- | --- |
| 3D 보드 | Three.js + WebGL 2 | 육각 19칸 보드, 지형·건물·물자 모델, 카메라 조작, 타일 선택과 배치 연출을 담당한다. [Three.js 렌더러](https://threejs.org/docs/pages/WebGLRenderer) |
| 웹 화면 | Vite + TypeScript + React | 대기실, 현재 차례, 자원 목록, 공개 계약, 거래 창 및 결과 화면을 HTML UI로 만든다. [Vite 빌드 문서](https://vite.dev/guide/build.html) |
| 3D 에셋 | Blender → GLB, KTX2 텍스처 | Blender에서 모델과 PBR 재질을 제작해 GLB로 내보낸다. 텍스처는 KTX2로 압축하고, 필요한 디코더 파일과 함께 방장 PC에서 제공한다. [Blender glTF 내보내기](https://docs.blender.org/manual/en/5.2/addons/scene_gltf2.html), [Three.js KTX2Loader](https://threejs.org/docs/pages/KTX2Loader.html) |
| LAN 멀티플레이 | Node.js + Socket.IO | 방장 PC의 서버가 Vite 빌드 결과와 에셋을 제공하고, 같은 주소에서 방과 게임 행동을 처리한다. 재접속 시 참가 토큰으로 자리를 확인하고 서버의 최신 게임 상태를 보낸다. [Socket.IO 동작 방식](https://socket.io/docs/v4/how-it-works/), [메시지 전달 보장](https://socket.io/docs/v4/delivery-guarantees/) |

방장 PC의 사설 IP를 사용하는 일반 HTTP 접속을 전제로 WebGL 2를 기본으로 한다. WebGPU에는 보안 컨텍스트가 필요하다. [MDN WebGPU](https://developer.mozilla.org/en-US/docs/Web/API/WebGPU_API), [MDN 보안 컨텍스트](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts)

타일마다 고정 ID를 두고 시작 배치와 건설 요청에서 해당 ID를 사용한다. 서버의 규칙 모듈이 턴과 자원을 판정하고, Three.js 보드는 서버가 확정한 결과를 받아 타일과 모델을 갱신한다. 이 구조로 대체 모델을 쓰는 동안에도 게임 규칙을 구현하고 확인할 수 있다.

## 그래픽 방향과 최적화

강가의 작은 중세 교역 마을을 비스듬히 내려다본다. 목재 칸은 숲과 통나무 더미, 곡물 칸은 밀 고랑과 짚단, 양모 칸은 울타리 친 목초지와 양 떼, 벽돌 칸은 둥근 벽돌 가마와 벽돌 더미, 석재 칸은 바위 언덕과 잘라 낸 돌, 시장은 천막과 상자로 표현한다. 기본 확대 수준에서도 물자 종류와 소유자를 알아볼 수 있게 형태·색·표식을 함께 쓴다.

## 구현 순서와 단계별 완료 조건

| 순서 | 작업 | 완료 조건 |
| --- | --- | --- |
| 1 | **LAN 대기실.** Vite 웹 앱과 Node.js 서버를 구성하고, 서버가 웹 파일 및 초대 링크 경로를 제공하게 한다. 방 생성, 닉네임, 준비, 시작을 연결한다. | 방장 PC와 같은 와이파이의 실제 휴대폰에서 초대 링크를 열어 같은 방에 들어간다. 3~4명이 준비하고 방장이 시작할 수 있다. |
| 2 | **작은 3D 테스트 장면.** 시장과 목재·곡물·석재 칸을 하나씩 만들고 직교 카메라, 확대, 타일 터치를 연결한다. | 휴대폰 기본 줌에서 물자 세 종류가 구분되고 원하는 타일을 쉽게 누를 수 있다. 카메라 이동 중 프레임 시간을 기록한다. |
| 3 | **서버 규칙 및 한 판 완주.** 전체 19칸 육각 보드는 임시 모델로 구성한다. 시작 배치, 공동 생산, 길·마을·도시 건설, 시장 교환, 납품과 턴 종료를 연결한다. | 6라운드가 끝나면 점수, 동점 판정, 최종 순위가 모든 참가자 화면에 일치한다. 차례가 아니거나 비용이 부족한 요청은 서버에서 거절한다. |
| 4 | **플레이어 간 교환과 재접속.** 제안·수락·거절·취소 및 참가 토큰을 연결한다. | 중복 수락으로 자원이 두 번 이동하지 않고, 새로고침이나 일시적인 연결 끊김 뒤 같은 자리와 최신 상태가 복구된다. 상대의 자원 종류별 수량은 전송되지 않는다. |
| 5 | **최종 보드 그래픽.** 작은 장면에서 검증한 재질과 표현을 19칸 전체 보드에 적용한다. 반복 에셋을 묶고, 보드가 바뀔 때만 렌더링한다. | 모바일에서 전체 보드의 첫 로딩과 움직임을 다시 측정한다. 자원과 계약을 읽을 수 있고 저해상도에서도 터치 판정이 일치한다. |
